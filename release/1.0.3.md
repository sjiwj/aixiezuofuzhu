## 之前那行「不可以商用」为什么不算数

v1.0.2 的 README 里写过「不可以商用」，但当时 `LICENSE` 还是 Apache-2.0。
许可证是授权合同，README 是说明文档——两者冲突时以 LICENSE 为准，所以那条声明**没有法律效力**。

现在两者一致：`LICENSE` 全文就是 PolyForm Noncommercial 1.0.0。

## 已经发出去的版本收不回来

```
v1.0.0 – v1.0.2   按 Apache License 2.0 发布
Apache-2.0 授予的许可「不可撤销」：
  已经按 Apache-2.0 取得副本的人，仍可继续按 Apache-2.0 使用（含商用）。
  本次变更只约束 v1.0.3 及以后的版本。
```
旧许可证原文存档在 `docs/legal/LICENSE-apache-2.0-through-v1.0.2.txt`，可自行核对。
