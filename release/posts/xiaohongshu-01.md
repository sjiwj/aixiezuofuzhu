**正文**

写小说写到第 4 章开始不对味——
人物突然失忆、前面埋的线接不上、读着像另一个人写的。

我以为是我提示词不行，直到我做了个对照实验👇

同一段设定、同一批模型，只换「喂进去的东西」：

📊 四组数据（对话占比 / 人名出现率）

A 背景+情节+角色卡 → 0.275 / 1.27
B 八拍模板「第一次受阻」→ **0.043 / 0.00** ⚠️
C 只有 226 字背景 → 0.183 / 0.69
D 同 C + 风格约束 → 0.273 / 0.72

B 组整篇没有一个人名，全是「他」。
不是模型不会写人，是**上游没告诉它谁在受阻**，它只能自己编。

还有个更刺眼的数：
我一条真实记录里，喂进去 2795 字，写出来 3418 字。
**喂的比写的还少。** 你让它猜，它就编。

为什么偏偏第 4 章？
1–3 章靠单章信息撑得住；到第 4 章要「承接」——谁受了伤、欠了谁钱、东西在谁手里。没写进上游，它只能忘掉或现编，一编就撞车。

我的改法就三件：
1️⃣ 一章拆 8 拍，每拍写清「谁、拿什么、在哪、做什么、不许做什么」
2️⃣ 章纲写成**场次表**（4 场，各写地点·时辰/发生什么/约字数）
3️⃣ 写完用 5 条硬线自己过一遍

第 3 条我自己也没全过😅
一章实测：最长段 109（要 ≤100）、对话 0.178（要 ≥0.25）、破折号 1（要 0）。
三处不过就写三处不过。

工具开源免费，稿子在自己电脑上，模型用自己的 key。
GitHub 搜 **sjiwj/jy**，README 里有「三步起壳」。
